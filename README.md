# 월급루팡 시뮬레이터 💼

> 사장님 몰래 딴짓하고 최고 땡땡이 기록에 도전하는 원탭 반응 게임.
> **목표: App Store(유료) / 웹 바이럴 1위.**

## 컨셉
사무실에서 사장님이 **등을 돌리면** 꾹 눌러 딴짓(폰질), **돌아보기 전에** 손을 뗀다.
걸리면 게임오버. 점수 = 오늘 땡땡이친 시간(초).

## 플레이 방법 (로컬)
```bash
python3 -m http.server 4321
# 브라우저에서 http://localhost:4321 접속
```
- **PC**: 스페이스바 또는 버튼 꾹
- **모바일**: 화면 꾹 누르기

## 핵심 메커니즘
- **3단 상태**: 등돌림(딴짓 찬스) → 움찔(경고) → 노려봄(위험)
- **페이크 동작**: 움찔했다가 안 돌아봄 → 버틴 사람은 콤보/점수 유지 (배짱 보상)
- **콤보 배속**: 연속으로 오래 딴짓할수록 점수 배율↑ (그리디 리스크)
- **난이도 상승**: 시간이 갈수록 안전구간·반응창이 짧아짐
- **등급**: 인턴 → 사원 → 대리 → 과장 → 부장 → 이사 → 월급루팡 마스터

## 기술
- 순수 정적 웹 (빌드 없음): `index.html` + `css/style.css` + `js/game.js`
- Canvas 파티클/점수 팝업, Web Audio 합성 사운드(에셋 0)
- 최고 기록 localStorage 저장, Web Share API 결과 공유
